## Workbook identity: `_meta` (2026-11-13)

Supersedes P2 and restores delivery-plan D26 (`_meta` naming another generation or term is a hard
error, also for sheet changes), now with `_meta` required.

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Rule in                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| K1  | `_meta` identifies the workbook's generation and term. It is checked when connecting and syncing, and never imported. It is required: `generation_code` and `education_term` must both be present and match the generation and term selected                                                                                                                                                                                                                        | google-sheets-template.md §1                           |
| K2  | Generation codes compare trimmed and case-insensitive, otherwise exactly (`GEN 2027` is not `GEN2027`). The term may be written `1`, `Term 1` or `T1`                                                                                                                                                                                                                                                                                                               | `packages/sheets/src/term-workbook/meta.ts`            |
| K3  | A missing tab or a blank or unreadable value is `META_MISSING`; a value that differs is `WORKBOOK_MISMATCH`, with a message showing both the workbook's and the selected generation and term (a `_meta` value over 100 characters is cut to 100 + "…"). Either is the 422 code even when other errors (a missing roster tab) are listed too. `TERM_MISMATCH` is no longer emitted                                                                                   | google-sheets-template.md §7                           |
| K4  | Connecting, checking or replacing a sheet with either error is refused (422) and saves nothing; the term's active sheet stays active and a pending one is untouched. The preview cannot be confirmed and the sync fails with that code before writing                                                                                                                                                                                                               | api-specification.md (Term workbooks, Synchronization) |
| K5  | Each refused request at connect / check / change is audited once as `source.connect.blocked` (selected and found values, no names or URLs). A change or connect is not recorded again when the same admin's latest identical entry (term, spreadsheet, code, found values) is a check within 10 minutes: it is the same attempt. Repeated checks, changes or connects each record. Two exactly simultaneous identical requests may both record (no lock, by choice) | api-specification.md (Audit & dashboard)               |

## Grade scale (2026-11-12)

Supersedes G1 (the scale of 2026-11-10). G2–G4 still apply.

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Rule in                                                                                                  |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| G5  | Official scale: A 85–100, B+ 80 to below 85, B 70 to below 80, C+ 65 to below 70, C 60 to below 65, D 50 to below 60, E 0 to below 50. Lower bound inclusive, compared on the displayed score (G2): 85.00 is A, 84.99 is B+, 50.00 is D, 49.99 is E. There is no F; E is the only fail (`is_pass` false)                                                                                                                                                                                                  | `packages/shared/src/grading/letters.ts`                                                                 |
| G6  | It replaces the bands of every generation (each scale marked confirmed) and is what every new generation gets. Grades are computed on read, so released results show the new letters at once                                                                                                                                                                                                                                                                                                              | migration `20261113090000_grade_scale_2026_11`                                                           |
| G7  | A final score and its letter are coloured by tone: green for A, B+, B and C+; yellow for C and D; red for E. Both the number and the letter; the letter always shows as text. Never on component marks, INCOMPLETE subjects or anything without a final score. They are the project's own success, warning and destructive (error) colours, unchanged; the letter's pill is outlined, not filled, so the text keeps at least 4.5:1 (light 4.59, dark 5.74 at the lowest). The API returns only the letter | `gradeTone` in `packages/shared/src/grading/letters.ts`; `apps/web/src/components/results/grade-tone.ts` |
